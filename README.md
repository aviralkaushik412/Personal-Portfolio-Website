# Aviral Kaushik — Portfolio

Personal portfolio built with React 19, TypeScript, Vite, Tailwind CSS v4, Framer Motion and Lenis.

```bash
npm install
npm run dev      # local dev server
npm run build    # type-check + production build to dist/
npm run lint     # oxlint
```

Content (projects, experience, skills, links) lives in `src/data/portfolio.ts`.
